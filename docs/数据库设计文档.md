  - is_goal（功能是不是用户目标）
      - 含义：这条功能本身是不是“用户真正想达成的业务目标”，来自功能抽取 prompt。
      - 用途：在 task_synthesis 中筛选任务目标，只对 is_goal=True 的功能生成 task，否则很多中间步骤（如“打开列表页”）
        也会被当成任务。
  - final（这个功能有没有被某条路径成功“收尾”过）
      - 含义：是否已经存在至少一个场景（在 step_assertions/scenarios 里）被 LLM 判定为“执行这一步就完成了这个功能”，我们在
        mark_final_functionalities 里把对应功能的 final 置为 True。

  - executable（这个功能还有没有可继续尝试的动作）
      - 含义：是否仍有与该功能相连、should_execute != False 的 transition；如果所有相关动作都被标为不可执行，就把功能

        动作”的功能。
